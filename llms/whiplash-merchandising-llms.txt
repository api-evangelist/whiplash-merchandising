# Whiplash Merchandising (Ryder E-commerce by Whiplash)

> Whiplash is an order-fulfillment and third-party logistics (3PL) platform for direct-to-consumer and ecommerce brands, offering pick-pack-ship, warehousing, inventory management, kitting, omnichannel order routing, and returns. It exposes the Rydership V2 REST API (formerly the Whiplash API) for programmatic fulfillment operations. Founded 2011, backed by 500 Global, acquired by Ryder System in 2021. API access is invite-only.

## APIs

- [Rydership API V2 developer portal](https://developers.getwhiplash.com): REST API reference (OpenAPI 3.1.0, 94 paths / 133 operations). Base URL https://www.getwhiplash.com/api/v2.

## Authentication

- OAuth 2.0 authorization_code + refresh_token, PKCE S256. Endpoints: authorize https://www.getwhiplash.com/oauth/authorize, token https://www.getwhiplash.com/oauth/token, dynamic registration https://www.getwhiplash.com/oauth/register.
- [Authorization server metadata (RFC 8414)](well-known/whiplash-merchandising-oauth-authorization-server.json)
- [Authentication profile](authentication/whiplash-merchandising-authentication.yml)

## Core resources

- orders, order_items, items (SKUs), shipnotices (inbound shipments), consumer_returns, customers, documents, bundle_items, packages, notification_subscriptions (webhooks), notification_events.
